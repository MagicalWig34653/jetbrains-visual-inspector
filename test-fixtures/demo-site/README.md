# demo-site

Manual test project for the Visual Inspector: open this folder as a project in WebStorm or PhpStorm,
then run "Open Current HTML File in Visual Inspector" on `index.html`.

Things to try: click the heading, a product (three repeated `li`), a table cell (the browser adds a
`tbody`), the text added by JavaScript (no source, expect "unmappable"), the link to `pages/about.html`
(second file, relative `../css/style.css`).
