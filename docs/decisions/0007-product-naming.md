# 0007: Product name and plugin identifiers

Status: Accepted (2026-11-08)

## Context

The project and repository are named `jetbrains-visual-inspector`. "JetBrains" is a third party's
trademark, so a plugin shown to users under that name could suggest it is an official product.

## Decision

The repository keeps its requested name. The plugin's display name is **Visual Inspector** and its
ID is `io.github.magicalwig34653.visualinspector`, derived from the GitHub account.

## Consequences

A Marketplace submission needs a review of the name against the current JetBrains rules; this is in
the backlog. The plugin ID must stay stable once a version is published.
